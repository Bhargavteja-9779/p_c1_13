Dear Editor,

We submit our Original Research article, "Detecting Glaucomatous Visual Field Progression From Few Tests Without False Alarms: An Open Benchmark With a True No-Change Arm", for consideration in *Ophthalmology and Therapy*.

Treatment of glaucoma is escalated when the visual field gets worse, and many new detectors, including machine-learning models, claim to detect this earlier. Most are judged by how many eyes they flag, so an earlier flag cannot be told apart from a false alarm. We compared ten detectors on the first three to six fields using a future-confirmed reference, a true no-change arm (patients tested weekly for 12 weeks), and an external data set from China measured with a different perimeter.

The main finding is practical. With three fields, the detectors that flagged the most progressors (57% and 26%, versus 19% for a simple trend test) raised false alarms in 22.4% and 27.7% of true no-change series, and the usual specificity estimate did not reveal this. No detector with a valid false-alarm rate beat the simple trend test significantly. We also show that a "shuffle audit", which any clinic can run on its own records, tracks the true false-alarm rate. We think these results are relevant to the journal's readers because they bear directly on when a progression flag should lead to escalation of therapy.

The analysis plan was written and dated before the final test data were analysed, all deviations are reported, and all code and result files are openly available. Only public, de-identified data were used. The manuscript has not been published and is not under consideration elsewhere, and all authors have approved it.
