We submit our Original Research article, "Early Detection of Glaucomatous Visual Field Progression Without False Alarms: A Benchmark With True No-Change Data", for consideration in *Ophthalmology and Therapy*.

Decisions to escalate glaucoma therapy rest on detecting visual field progression. Many new methods, including machine-learning tools, claim earlier detection from fewer tests. We asked whether these earlier flags are real. We built an open benchmark with three parts that are rarely combined: a true no-change arm (12-week retest series in which progression is impossible), a reference based on each eye's full follow-up, and an external clinic.

The main findings are:

- The only detector that significantly beat a simple trend test at three tests did so by raising false alarms in {{m:D6:3:fpr_true_null}} of no-change series, although its specificity against the conventional reference was {{m:D6:3:spec}}.
- A machine-learning model thresholded in the usual way gave {{m:D8:3:fpr_true_null}} false alarms at three tests.
- No detector with valid false alarms beat the simple trend test at three to six tests, in either clinic.
- A simple "shuffle audit", which any clinic can run on its own records, tracked the true false-alarm rate (Spearman ρ = {{s:spearman_rho}}).

We believe these results are directly useful to clinicians who must decide when to escalate treatment, and to those who evaluate new progression tools. The analysis plan was written and time-stamped before the final analysis; all data are public and all code will be released.
